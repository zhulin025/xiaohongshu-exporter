# 小红书收藏夹导出助手

一个功能强大的Chrome浏览器插件,用于导出小红书收藏夹到飞书、Notion和本地文件。

## ✨ 功能特性

### 数据采集
- 🔍 自动采集小红书收藏夹中的所有笔记
- 🎯 **[新]** 指定采集范围(从第N条到第M条)
- ⏸️ **[新]** 暂停采集功能,已采集数据可导出
- 📊 提取完整的笔记信息(标题、链接、作者、封面图等)
- 🔄 自动滚动加载,确保采集完整数据
- 💾 本地缓存已采集数据,避免重复采集

### 多平台导出
- 📁 **本地导出**: 支持JSON、CSV、HTML、Markdown等多种格式
- 🚀 **飞书多维表格**: 直接导出到飞书多维表格,方便团队协作
- 📝 **Notion数据库**: 导出到Notion数据库,融入知识管理系统

### 高级功能
- 🖼️ 可选择同时下载收藏的图片
- ⚙️ 灵活的配置选项和高级设置
- 🔒 安全的API密钥存储
- 📈 实时进度显示
- 🔄 失败自动重试机制

## 🚀 使用指南

### 1. 采集收藏夹数据

#### 基本采集(采集全部)
1. 打开小红书网页版: https://www.xiaohongshu.com
2. 登录你的账号
3. 进入"我的收藏"页面
4. 点击浏览器工具栏中的插件图标
5. 点击"开始采集收藏夹"按钮
6. 等待采集完成(会自动滚动加载所有收藏)

#### 指定范围采集 **[新]**
1. 勾选"指定采集范围"
2. 输入起始位置(如: 100)
3. 输入结束位置(如: 200)
4. 点击"开始采集收藏夹"
5. 插件会只采集指定范围内的收藏

**使用场景**:
- 收藏内容较多时,分批采集(如每次100条)
- 只需要最新的N条收藏
- 测试功能时采集少量数据

#### 暂停采集 **[新]**
1. 开始采集后,会出现"暂停采集"按钮
2. 点击"暂停采集"按钮
3. 采集立即停止,已采集的数据自动保存
4. 可以直接导出已采集的部分数据

**使用场景**:
- 采集时间过长,需要中断
- 已经采集到需要的内容
- 网络不稳定,先保存已采集的数据

### 2. 导出到本地

1. 采集完成后,选择"本地文件"导出目标
2. 选择导出格式(JSON/CSV/HTML/Markdown)
3. 可选择是否同时下载图片
4. 点击"开始导出"按钮
5. 选择保存位置,完成导出

### 3. 导出到飞书

#### 准备工作
1. 访问[飞书开放平台](https://open.feishu.cn/app)
2. 创建一个自建应用
3. 获取App ID和App Secret
4. 开通以下权限:
   - `bitable:app` (多维表格应用权限)
   - `bitable:table` (数据表权限)

#### 导出步骤
1. 在插件中点击"配置飞书API"
2. 输入App ID和App Secret
3. 选择"飞书多维表格"导出目标
4. 点击"开始导出"
5. 导出完成后会在飞书中自动创建多维表格

### 4. 导出到Notion

#### 准备工作
1. 访问[Notion集成设置](https://www.notion.so/my-integrations)
2. 创建一个新的内部集成(Internal Integration)
3. 复制Integration Token
4. 在Notion中创建一个页面,并授权集成访问

#### 导出步骤
1. 在插件中点击"配置Notion API"
2. 输入Integration Token
3. (可选)输入目标数据库ID,不填则自动创建
4. 选择"Notion数据库"导出目标
5. 点击"开始导出"
6. 导出完成后会在Notion中创建数据库或页面

## ⚙️ 高级设置

点击插件popup底部的"高级设置"按钮,可以配置:

- **API密钥管理**: 统一管理飞书和Notion的API密钥
- **默认导出格式**: 设置本地导出的默认格式
- **并发控制**: 调整API请求的并发数量
- **重试次数**: 设置失败重试次数
- **调试模式**: 启用详细的调试日志
- **数据管理**: 清除缓存、导出/导入配置

## 📋 数据格式说明

### JSON格式
```json
[
  {
    "id": "笔记ID",
    "title": "笔记标题",
    "url": "https://www.xiaohongshu.com/explore/...",
    "coverImage": "封面图片URL",
    "author": {
      "nickname": "作者昵称"
    },
    "collectTime": "2024-01-01T00:00:00.000Z",
    "type": "图文"
  }
]
```

### CSV格式
包含以下列:
- 标题
- 链接
- 作者
- 收藏时间
- 类型

### HTML格式
生成一个美观的网页,以卡片形式展示所有收藏。

### Markdown格式
生成Markdown文档,每条收藏作为一个章节。

- **Manifest V3**: 使用最新的Chrome扩展API

- **Popup界面**: 提供友好的用户交互界面

## 🐛 常见问题

### Q: 采集时提示"请先打开小红书收藏夹页面"
A: 请确保在小红书网页版的收藏夹页面使用插件,而不是首页或其他页面。

### Q: 导出到飞书/Notion失败
A: 请检查:
1. API密钥是否正确配置
2. 是否已授予相应的权限
3. 网络连接是否正常
4. 是否触发了API限流(可降低并发数)

### Q: 采集的数据不完整
A: 可能原因:
1. 页面未完全加载完成
2. 小红书页面结构发生变化
3. 网络连接不稳定

解决方法: 刷新页面后重新采集,或联系开发者反馈问题。

### Q: 图片下载失败
A: 部分图片可能有防盗链保护,建议在导出HTML格式时保留图片链接,在浏览器中查看。
